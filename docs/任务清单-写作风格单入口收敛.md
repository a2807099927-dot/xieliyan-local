# 写梨眼：写作风格单入口收敛 —— 任务清单

> 版本：v1（2026-08-03）
> 决策（用户拍板）：**只需要一个「写作风格」提示词入口**。三套自定义提示词（planner/writer/editor）是内部实现细节，不暴露 UI，不做三套编辑入口。
> 背景（代码已核实）：
> - `agentMode: 'builtin' | 'custom'`，custom 模式用三套 prompt（customPlannerPrompt/customWriterPrompt/customEditorPrompt）替换内置
> - 旧版「写作风格自定义」升级时被迁移进 `customWriterPrompt`（`useConfigStore.ts:59-61`），三套 UI 从未存在
> - **Bug**：用户改风格写 `styleProfiles[].styleInstruction`（StyleSettingsTab），但写手 prompt 读 `customWriterPrompt`——两条线不同步，用户改了风格写手不生效

---

## 0. 目标

用户视角**只有一个写作风格入口**（现状设置页），改风格必须真实生效于写手 prompt；内部三套 prompt 收敛，不再打架。

## 1. 核心修复：风格变更同步

### T1 写手 prompt 统一读风格配置（消除双线）

- **现状**：`getRolePrompt('writer')` 读 `customWriterPrompt`（可能来自旧迁移）；`buildWritingPromptBundle` 的 `withStyle` 又独立读 `resolveStyleForBook` 的 `styleInstruction`——两条线
- **改法**：写手角色 prompt 改为**只从风格配置解析**，`customWriterPrompt` 降级为纯兼容兜底：
  ```
  写手角色提示词 = resolveStyleForBook(book, config).styleInstruction
                ?? customWriterPrompt（仅当风格未配置时，兼容旧迁移数据）
                ?? getPromptSync('agent_writing_system')
  ```
  即：用户改风格 → `styleProfiles.styleInstruction` 更新 → 写手 prompt 自动跟随，不再有「改风格不生效」
- **文件**：`src/Agent/skills/writingSkill.ts`（`getRolePrompt` writer 分支）
- **验收**：改风格后写手 prompt 反映新风格（测试断言）；旧迁移数据仍兼容

### T2 移除迁移继承，防止旧数据污染

- **现状**：`useConfigStore.ts:59-61` 把旧 `styleInstruction` 迁进 `customWriterPrompt`，之后风格再改 `customWriterPrompt` 不跟
- **改法**：迁移逻辑保留（老配置兼容），但**迁移后不再作为权威源**——T1 改完，写手读风格配置，`customWriterPrompt` 只是兜底。可选：迁移时同步加注释「此字段已降级为兼容兜底」
- **文件**：`src/store/useConfigStore.ts`（注释/逻辑微调）
- **验收**：老配置升级后写手风格正常；新配置不产生 `customWriterPrompt` 污染

## 2. 收敛：三套 prompt 定位

### T3 明确三套 prompt 的最终定位（文档级）

- `customPlannerPrompt` / `customEditorPrompt`：保留为**高级配置字段**（配置文件可改），不暴露 UI；内置 fallback 已兜底（`getPromptSync`）
- `customWriterPrompt`：降级为兼容兜底，权威源 = 风格配置（T1）
- **文件**：`docs/` 新增/更新说明（可选，注释即可）
- **验收**：无 UI 变化；三字段在配置里合法但不宣传

### T4 不做三套编辑 UI（明确拒绝）

- 不开「设置页加规划师/写手/审稿三个输入框」任务——用户只需要一个写作风格入口
- 现状人设框（`customPersona`）保持，它是 Agent 人格不是写作风格，两回事

## 3. 验证

### T5 测试 + 全量验证

- 新增测试：
  - 写手 prompt 跟随 `styleProfiles.styleInstruction` 变化
  - 无风格配置时 fallback 到 `customWriterPrompt`（旧迁移兼容）
  - 两者都无时 fallback 到内置 `agent_writing_system`
  - 改风格后不依赖 `customWriterPrompt`（bug 回归测试）
- `npx tsc --noEmit` + `npx vitest run` 全绿
- **文件**：`src/Agent/__tests__/promptLayering.test.ts`（扩展）
- **验收**：全量测试绿，无回归

---

## 4. 验收标准

1. 设置页改写作风格 → 写手 prompt 立即反映新风格（无需重启/迁移）
2. 用户视角只有一个风格入口，无三套提示词 UI
3. 旧迁移数据（customWriterPrompt 有值）仍能出正文，不报错
4. tsc 0 错误 + 全量测试绿
