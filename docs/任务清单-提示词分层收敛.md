# 写梨眼 Agent：提示词分层收敛 —— 任务清单

> 版本：v1（2026-08-03）
> 性质：落实「每阶段最小必要集 + 自定义提示词按角色注入 + 不一股脑全塞」
> 上游讨论：同题材研究搜一次定型 + 自定义提示词分层边界（猫猫虫 2026-08-03）
> 关联现状（已核实）：
> - `buildWritingPromptBundle(book, role)` 是**所有环节共用基座**，每次塞全套（角色提示词+设定卡+剧情卡+角色卡+文风）
> - wizard 流程（`newBookWizard.ts`）**不走 bundle**，自定义提示词在规划阶段完全不生效
> - `buildWriterSystemPrompt` 叠得最厚（基座+复盘+研究+约束+细纲+已有正文）

---

## 0. 分层原则（先定规则，再改代码）

```
每个环节只注入「该环节必需」的信息，其余靠引用不靠粘贴。

系统硬规则（细纲结构/正文纯净/防编造）
  > 用户自定义提示词（对应角色，原样注入，不改写）
  > 同题材研究结论（规划层参考）
  > 模型自由发挥
```

| 环节 | 必须注入 | 不注入 |
|---|---|---|
| wizard 第1步 方向卡 | 设定卡（精简）+ 题材打法 | 角色提示词、文风、剧情卡 |
| wizard 第2步 档案 | 设定卡 + 选中方向 | 角色提示词、文风 |
| wizard 第3步 写法决策 | 档案 + **planner 自定义提示词** + 题材打法 | writer 提示词、文风 |
| wizard 第4步 剧情规划 | 档案 + 写法决策 + **planner 提示词** + 研究结论 | 剧情卡、正文 |
| wizard 第5步 章节大纲 | 卷规划 + **planner 提示词** | 研究结论全文 |
| wizard 第6步 大纲审查 | 大纲 + 卷规划 | 角色提示词（审查走 editor 提示词） |
| 章纲讨论/正式细纲（plan/formalize） | 设定卡+剧情卡 + **planner 提示词** | writer 提示词、文风 |
| 写正文 | 细纲 + 复盘决策摘要 + **writer 提示词 + 文风** + 硬约束 | 研究结论全文、planner/editor 提示词 |
| 写后 review | **editor 提示词** + 审查清单 | 其他两套提示词、文风 |

## 1. 任务清单

### T1 收敛 bundle 基座：按环节裁剪（核心）

- **现状**：`buildWritingPromptBundle` 一刀切塞全套，所有环节共用
- **改法**：给 bundle 加选项 `{ withRolePrompt?: boolean; withStoryCanon?: boolean; withStyle?: boolean }`（默认全开保持兼容），各环节按上表显式传：
  - planner 环节（章纲讨论/正式细纲）：`{ withRolePrompt: true, withStoryCanon: true, withStyle: false }` —— 规划不带文风
  - writer 环节（写正文）：`{ withRolePrompt: true, withStoryCanon: true, withStyle: true }` —— 写作带文风
  - editor 环节（写后 review）：`{ withRolePrompt: true, withStoryCanon: false, withStyle: false }` —— 审查不需要设定卡全文，带审查清单即可
- **文件**：`src/Agent/skills/writingSkill.ts`
- **验收**：各环节 prompt 只含上表「必须注入」列；不破坏现有调用（默认参数兼容）

### T2 wizard 阶段接入自定义提示词

- **现状**：`newBookWizard.ts` 用 `buildNewBookBaseBlocks`（设定卡+题材打法），自定义提示词全程不生效
- **改法**：
  - 第 3 步写法决策：注入 `customPlannerPrompt`（用户对「这本书怎么写」的偏好，这里最该出现）
  - 第 4 步剧情规划：注入 `customPlannerPrompt` + 研究结论
  - 第 6 步大纲审查：注入 `customEditorPrompt`
  - 通过 `resolveConfig` 读 `ai.customPlannerPrompt` / `customEditorPrompt`（已有配置字段，不用新造）
- **文件**：`src/Agent/newBookWizard.ts`、`src/Agent/openingDirection.ts`（prompt 构建函数加可选参数）
- **验收**：用户填了 planner 自定义提示词后，wizard 第 3/4 步产出体现该偏好

### T3 写正文环节减负

- **现状**：`buildWriterSystemPrompt` 叠基座全套 + 复盘 + 研究 + 约束 + 细纲 + 已有正文
- **改法**：
  - bundle 用 `withStyle: true`（writer 需要文风），但 `withStoryCanon` 视情况：正文 prompt 里已另有「细纲 + 复盘决策摘要」，设定卡全文可省（复盘时已看过）——改为 `withStoryCanon: false`，让 writer 聚焦
  - 复盘决策摘要（`formatPreWriteDecisionForWriter`）保留——这是「这章怎么打」的直接指令
  - 研究结论全文不再进正文（只在规划阶段用），正文只带「差异化已定」一句引用
- **文件**：`src/Agent/skills/writingSkill.ts`、`src/Agent/tools/creativeTools.ts`、`src/Agent/useAgentSession.ts`
- **验收**：正文 prompt 比改造前短（可测 fullBlock 长度），writer 收到的指令更聚焦

### T4 自定义提示词总量引导

- **现状**：设置页 max 6000 字，用户可能写超长
- **改法**：设置页（`AgentSettingsTab.tsx`）三套提示词加提示文案：「建议 200 字以内，写清楚文风偏好/角色要求即可；越长越容易被稀释」
- **文件**：`src/components/modals/settings/AgentSettingsTab.tsx`
- **验收**：设置页有引导文案；不改存储逻辑（超长仍接受，但提示）

### T5 测试 + 全量验证

- 新增测试：bundle 选项裁剪（planner 不带文风 / editor 不带设定卡）、wizard 第 3/4 步含 planner 提示词、正文 prompt 不含研究结论全文
- `npx tsc --noEmit` + `npx vitest run` 全绿
- **文件**：`src/Agent/__tests__/`（新增或扩展现有）
- **验收**：全量测试绿，无回归

## 2. 明确不做（边界）

- **不改写/不提取用户自定义提示词**——原样注入，加工=扭曲
- **不做「自动摘要自定义提示词」**——用户写的保持原样，超长靠引导不靠截断
- **不改 `buildWritingPromptBundle` 的导出签名**（加可选参数，默认兼容）
- **不动现有 review 清单逻辑**（`loadReviewSkill` 不变）

---

## 3. 验收标准（猫猫虫验收用）

1. 各环节 prompt 与 §0 分层表一致：planner 环节无文风、editor 环节无设定卡、wizard 3/4 步有 planner 提示词
2. 正文 prompt 长度比改造前明显下降（fullBlock 可比）
3. 用户自定义提示词在对应环节**原样出现**，未被改写
4. 研究结论只在规划阶段出现，正文不携带全文
5. tsc 0 错误 + 全量测试绿
