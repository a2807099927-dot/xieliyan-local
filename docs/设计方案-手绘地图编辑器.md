# 手绘地图编辑器设计方案

## 目标
替换 FMG（太卡），做一个轻量的 Canvas 手绘地图编辑器：
- 可一键自动生成大陆形状 + 地形 + 板块划分
- 可手动涂抹修改地形材质
- 可标注命名（国家、城市、河流）
- AI 辅助起名和编辑
- 流畅不卡（Canvas 位图渲染）

## FMG 核心算法参考（可复用的思路）

### 1. 大陆形状生成
- **方法**：Perlin/Simplex 噪声生成高度图，阈值切割得到海岸线
- **FMG 实现**：`HeightmapGenerator.generate(grid)` 生成 grid.cells.h 数组
- **模板**：Continents（多大陆）、Archipelago（群岛）、Pangea（盘古大陆）、Peninsula（半岛）、Isthmus（地峡）、Atoll（环礁）、Mediterranean（地中海）、Highland（高地）、Volcano（火山岛）
- **简化方案**：用 2D Perlin 噪声 + 阈值，h >= 20 为陆地，< 20 为海洋

### 2. 地形/生物群落分配
- **FMG 实现**：`Biomes.define()` 根据温度+降水+高度决定生物群落
- **简化方案**：根据高度直接分配：
  - h < 20: 海洋（蓝色）
  - 20-30: 沿海平原/草地（浅绿）
  - 30-50: 森林（深绿）
  - 50-65: 丘陵（黄绿）
  - 65-80: 山脉（棕色）
  - 80+: 雪山（白色）
- 可叠加纬度因素：高纬度偏冷（苔原/雪地），低纬度偏热（沙漠/热带）

### 3. 河流生成
- **FMG 实现**：从高处向低处寻路（类似 A* 但沿梯度下降）
- **简化方案**：从山脉高点开始，每步向最低邻居移动，直到到达海洋或湖泊
- 河流宽度随流程增加

### 4. 国家板块划分
- **FMG 实现**：Voronoi 区域 + Dijkstra 扩张算法（`BurgsAndStates.expandStates()`）
- **简化方案**：
  1. 在陆地上随机撒 N 个种子点（N = 国家数量）
  2. 用 Voronoi 或 flood-fill 从种子点向外扩张
  3. 每个区域分配一个颜色
- 边界线：相邻不同国家的像素连线

### 5. 城市放置
- **FMG 实现**：根据人口密度、沿海、河流交汇等因素评分
- **简化方案**：每个国家放 1-3 个城市点，优先放在河流旁或沿海

### 6. 标签渲染
- **FMG 实现**：SVG text 沿路径弯曲
- **简化方案**：Canvas fillText，大国名字大号字体居中，城市小号字体

## 技术方案

### 渲染层（从底到顶）
1. **海洋层**：纯色或渐变蓝
2. **地形层**：Canvas 位图，每个像素对应一种地形材质
3. **国界层**：半透明彩色区域 + 边界线
4. **河流层**：曲线路径
5. **标注层**：文字标签（国名、城名）
6. **交互层**：鼠标事件、笔刷预览

### 工具栏
- 笔刷：草地/森林/山脉/雪地/沙漠/水域/沼泽
- 标记：城市/首都/要塞/港口
- 线条：河流/道路/边界
- 文字：自由标注
- 橡皮擦
- 选区工具（框选区域命名为国家）

### 自动生成
- "随机生成"按钮：Perlin 噪声 → 高度图 → 地形分配 → 板块划分 → 城市放置
- 生成后用户可手动修改任何部分

### AI 集成
- AI 起名：根据地形特征为国家/城市起名
- AI 编辑：自然语言描述修改（"把北方变成雪地"、"在两国之间加一条河"）
- AI 描述：根据地图生成世界观文字描述

### 数据结构
```typescript
interface MapData {
  width: number;
  height: number;
  heightMap: Float32Array;      // 高度图
  biomeMap: Uint8Array;         // 地形类型
  stateMap: Uint16Array;        // 国家归属
  states: MapState[];           // 国家列表
  burgs: MapBurg[];             // 城市列表
  rivers: MapRiver[];           // 河流列表
  labels: MapLabel[];           // 自由标注
}
```

### 性能
- Canvas 2D 渲染，纯位图操作
- 涂抹 = 修改像素数组 + 局部重绘
- 缩放/拖动 = CSS transform（不重绘）
- 预期：60fps 流畅
