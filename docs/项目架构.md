## 一·B 写梨眼差异化核心功能

这些是用户视角的"招牌功能"，不只是基础写作工具：

### ⭐ 段尾回车 → 自动润色（核心卖点）

**用户操作**：写完段落按 Enter → 继续打字 → 写梨眼后台分析上一段

**技术链路**：
1. `TiptapEditor.tsx` 拦截 `keydown` Enter → 进入 `pendingOptimization` 状态，记下要分析的段
2. `useEditorTransactionFlow.ts` 监听 ProseMirror 事务，累计在新段输入字符数
3. 输入≥2 字符 → `scheduleParagraphScan()` 触发 AI 分析
4. AI 返回 JSON 修改建议（用词/语序/描写）
5. `inlineSuggestionPlugin` 在编辑器内高亮被建议范围
6. 右侧 `wz-inline-suggestion-rail` 卡片展示建议
7. 一键替换 / 忽略

**关键文件**：
- `src/components/editor/TiptapEditor.tsx`（核心状态 + 事件）
- `src/hooks/useEditorTransactionFlow.ts`（事务监听）
- `src/hooks/useInlineSuggestionRailLayout.ts`（卡片定位）
- 样式 `wz-inline-suggestion-*` in `styles.css`

**取消条件**：Backspace/Delete/方向键/Tab/Escape/Ctrl+组合键 → 立即取消

### ⭐ Agent 助手双模式

- **询问剧情**：本地检索（不消耗 token，简单定位类问题）
- **润色代写**：直接走 AI（描写/改写/段落生成）
- 自动检测大纲 → 弹"批量创建章节"任务卡
- 自动检测角色 → 弹"角色卡建议"任务卡

### ⭐ 角色名 Hover 卡片

鼠标悬停文中的角色名 → tippy 弹出角色档案预览（含装备/技能/简介/关系）

文件：`src/components/editor/CharacterTooltip.tsx` + `src/hooks/useCharacterHoverCard.ts`

### ⭐ AI 结构推演

智能整理弹窗内的高级模块，输出剧情结构树：
- 弧线（arc）→ 节点（plot point）→ 时间线
- 三种视图：树状 / 时间线 / 文本

文件：`src/components/modals/memory-bank/ui/InferencePanel.tsx` + `inferenceEngine.ts`

### ⭐ 角色档案 + 装备 + 技能聚合

- 自动从书中提取角色（IPC `RESOURCES_EXTRACT_ROLES`）
- 装备/技能从所有角色聚合去重，按"几位拥有"展示
- 支持新建/编辑/删除卡片，反向写回所有相关角色

### ⭐ 续写独立窗口

AI 续写过程跑在独立 Electron 窗口（`ContinuationDetached.tsx`），不阻塞主编辑器，可同时继续写。

### ⭐ 简化模式（Mac 友好）

设置 → 界面与外观 → 启用后：
- 关闭所有 backdrop-filter
- 关闭所有循环动画 / 过渡 / 阴影
- 隐藏壁纸图层
- GPU 占用预期下降 70-80%

## 三、关键数据流

### 3.1 写作主流程

```
用户输入 → Tiptap 编辑器 → useEditorTransactionFlow
  → 防抖 600ms → useChapterPersistence 写本地 books/{bookId}/book.json
  → 触发 applyCharacterHighlights（角色名高亮扫描）
```

### 3.2 AI 续写流程

```
用户右键 → EditorContextMenu → useContinuationFlow
  → 拼装上下文 (referenceBuilder) → 注入题材提示词 (stylePresetCatalog)
  → ai/manager.ts → IPC 调主进程 ai.ts → fetch 各 Provider
  → 流式回调 → DiffCard 展示对比 → 用户采纳/拒绝
```

### 3.3 Agent 助手流程

```
用户输入问题 → AgentChatPanel → pipeline.ts
  ├─ 简单定位（"在哪章"等）→ localSearch.ts → 直接返回
  └─ 复杂分析 → memoryRetrieval（剧情档案） + bookContext（角色档案）
        → messageBuilder 拼 OpenAI 消息 → ai/manager 调 AI
        → 流式回复 → 检测大纲/角色卡 → 展示批量任务卡
```

### 3.4 云同步流程

```
关闭软件 → before-quit → webdav-sync.ts:syncUpload
  → 遍历 books/ 目录 → 逐文件 PUT 到坚果云
  → 失败静默（不阻塞退出）

登录其他设备 → TitleBar.tsx 检查 token → 拉 /sync/load-config
  → 自动应用 WebDAV 配置 → 用户手动点云图标触发下载
```

### 3.5 账号系统流程

```
注册 → 发送验证码（/auth/send-code → Resend → 用户邮箱）
  → 校验验证码 → /auth/register（写 D1） → 返回 JWT token
  → 客户端 localStorage 存 xly_client_token

登录 → /auth/login → 校验密码哈希 → 返回 JWT
  → 锁定机制：5次失败锁15分钟

找回密码 → /auth/forgot-password → 邮件含 token 链接
  → 用户访问 reset-password.html → /auth/reset-password
```

## 四、关键约束与不变量

### 4.1 数据存储约定

- **书籍数据**：`{workspace}/books/{bookId}/book.json`
- **剧情档案**：`{workspace}/books/{bookId}/memory.json`
- **角色索引**：`{workspace}/books/{bookId}/archive-index.json`（自动生成，不编辑）
- **配置**：`%APPDATA%/xie-li-yan/config.json`
- **日志**：`%APPDATA%/xie-li-yan/logs/`

### 4.2 IPC 通道命名规范

- 全部走 `IPC_CHANNELS` 常量（`shared/ipc-contract.ts`）
- 主进程通过 `ipcMain.handle` 注册
- 预加载通过 `contextBridge.exposeInMainWorld` 暴露 `window.electron.*`

### 4.3 安全约定

- 所有后端密钥仅存 Cloudflare 环境变量
- 客户端调 API 必须带 HMAC 签名头（apiHeaders.ts）
- 用户密码 SHA-256 + salt 哈希存储
- WebDAV 凭据 base64 编码存 D1（待升级 AES）

### 4.4 构建产物约定

- `dist/main/` - 主进程
- `dist/preload/` - 预加载
- `dist/renderer/` - 渲染层
- `runtime.dat` 必须在打包前由 `build:agent` 重新生成
- `obfuscate.cjs` 必须在 build 之后运行

## 六、维护建议

### 增加新功能时

1. **新增页面**：放 `src/pages/`，并在 `App.tsx` 加路由
2. **新增 IPC 通道**：先在 `shared/ipc-contract.ts` 加常量
3. **新增 Provider**：在 `src/ai/adapters/` 加适配器
4. **新增题材**：在 `electron/prompts/genres/` 加文件并在 index 注册

### 改动核心数据结构时

- `Book`/`Chapter`/`MemoryBankEntry` 等改动必须考虑老存档兼容
- 字段新增用可选，删除前先做迁移脚本
- 改动需同步更新 `types/index.ts`

### 性能注意

- 编辑器事务防抖至少 500ms
- 大文件操作用 IPC 异步，避免阻塞渲染
- 列表虚拟化（章节数 >100 时考虑）
