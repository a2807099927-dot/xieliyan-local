# 拆书方法论素材整理

> 用于重做小说实验室"拆书分析"模块的提示词设计  
> 整理时间：2026-05-27

---

## 一、矛盾驱动论（剧情推进的核心）

### 核心观点
- 矛盾 = 冲突 = 剧情推动力
- 解决冲突的过程本身就是剧情线路
- 根据冲突引申出对后续剧情的期待 = 故事脉络

### 矛盾类型清单

| 类型 | 定义 | 经典案例 |
|------|------|----------|
| 身份矛盾 | 通过身份带来的外部压力创造矛盾 | 穿越即逃犯、穷困潦倒的渔夫/马夫、被宗门放弃的修士、要夺嫡的皇子 |
| 环境矛盾 | 跳过身份，直接描写外部压力 | 全球变冷、生化危机、全民游戏、无限流 |
| 生死危机矛盾 | 打了小的来老的，换地图发育回来干仗 | 武动乾坤（林动败走东玄域）、遮天（黑皇带主角跑路东荒） |
| 阶层矛盾 | 每到新层级诞生新诉求，为完成诉求面对新困境 | 城外→城中→更高阶层，欲望递进驱动剧情 |
| 唯一性矛盾 | 你前进就触碰别人利益 | 诡秘之主（序列唯一性）、玄鉴仙族（果位唯一性）、苟在魔门（求金法仪） |
| 理念矛盾 | 理想主义vs现实的冲突 | 遮天（大道之争）、一世之尊（天意高难问）、三体（章北海） |
| 感情矛盾 | 爱而不得、得而不爱、修罗场 | 各类感情线展开 |

### 矛盾推进公式
```
初始矛盾 → 解决过程（剧情线） → 新矛盾诞生 → 循环
```

### 经典结构模式

**打了小的来老的（生死危机循环）：**
```
被强敌压制 → 换地图 → 发育变强 → 回来干仗 → 开爽 → 新强敌出现 → 循环
```

**阶层递进：**
```
吃不起饭 → 有吃的了想有房 → 有房了想有产业 → 有产业想活久 → 能修仙了想变强 → 成仙了发现仙人也是耗材 → 继续往上
```

**唯一性压力：**
```
你只要升级 → 就触碰既得利益者 → 同序列全是敌人 → 天然矛盾 → 不需要额外制造冲突
```

### 身份矛盾贯穿全文的高级用法
- 一世之尊：主角身份卷入顶尖战力布局，全文处于"天意高难问"的压力中
- 诡秘之主：主角是上位者棋子，中后期碰撞产生强烈高潮
- 佛本是道：钦定天道圣人，使命是清算因果，但被其他圣人布局

### 注意事项
- 支线不要写太多，主线推进不能太慢
- 务必认真做大纲，防止崩书
- 网文即人文，生活中能调动情绪的事都可以拆分应用

## 二、期待感理论（比爽点更重要）

### 核心观点
- **期待感 > 爽点**：拉住读者的不是"爽到了"，而是"即将要爽"
- 大高潮/大爽点过后追订会下跌 → 证明读者追的是"期待爽"而不是"爽本身"
- 只要开篇能让读者有期待感，就是好开篇

### 期待感的三个维度
1. **金手指期待** — 这个能力还能怎么用？
2. **人物期待** — 这个角色接下来会怎样？
3. **故事期待** — 剧情会怎么发展？

### 开篇制造期待感的方法

**身份欺骗式开头：**
```
主角以为自己是穷人 → 读者也以为 → 反转揭示主角其实是富二代/有背景
→ 读者期待：主角什么时候知道真相？知道后会怎样？
```

**三重期待叠加法：**
1. 故事期待（身份反转/悬念）
2. 人物期待（有趣的配角/暧昧关系）
3. 金手指期待（能力还没完全展示）

### 信息差制造期待感
- **读者知道但主角不知道** → 读者产生优越感 + "等打脸"的期待
- **读者知道但反派不知道** → "你等着吧"的爽感
- 这种期待感本身就是情绪价值，不需要即时兑现

### 期待感管理原则
- 好角色不要经常用，藏一下偶尔遛一遛
- 大爽点后要立刻挂新钩子，不能让期待感断档
- 多线推进 + 多重期待感可以避免高潮后追订下跌

## 三、人设分层描写法

### 核心原则
- 最忌讳上来把人设全抛出来
- 一层层地写，逐步加深

### 分层步骤

**第一层：类型模型（让读者一眼知道类型）**
- 女：萝莉、少女、御姐、少妇
- 男：铁塔型、儒雅型、阴鸷型

**第二层：特点标签（贴标签 + 重复强化）**
- 外貌特征：胸大、腿长、小麦色皮肤、鹰钩鼻、身高两米一
- 行为标签：萌萌的一笑、冷哼一声、习惯性摸鼻子
- 不要怕重复！重复是在深化记忆

**第三层：深化（二选一）**

| 方式 | 做法 | 效果 |
|------|------|------|
| 顺承 | 为性格找原因（家庭/经历/信仰） | 角色更立体 |
| 打破 | 反转已建立的印象 | 产生张力和惊喜 |

**顺承举例：**
- 角色懦弱 → 因为家里贫穷母亲卧病
- 反派残忍 → 因为信奉自然主义要杀光人类

**打破举例：**
- 天然呆女孩 → 其实什么都知道，只是因为爱主角才装傻
- 被霸凌的女孩 → 下一章把霸凌者踩脚下，一切是为了接近主角

### 角色管理技巧

1. **以角色带角色** — 女主讨喜→写女主爸妈/姐姐/闺蜜/网友，像网一样编织
2. **好角色要藏着用** — 偶尔拿出来遛一遛，给读者期待感
3. **不喜欢的角色自然下线** — 不是写死，是让他"神隐"，偶尔再出来
4. **不要舍不得角色** — 读者不感兴趣了就换新的

## 四、日常写法

### 内功：观察生活
- 女孩说话的表情
- 楼下大爷聊天的神情、动作
- 所有能调动情绪的细节

### 外功：找梗→提取内核→举一反三

**原梗：**
> "那个女人真漂亮？" "有多漂亮？" "跟你一样漂亮。" "哦，那是满漂亮的。"

**化用内核：**
> "他真有钱。" "有多有钱？" "跟你一样有钱。" "是吗？那他倒是蛮有钱的。"

一个梗可以用在七八个场景里，章章有梗。

## 五、拆书分析应该输出什么（产品设计方向）

基于以上方法论，小说实验室的拆书分析应该输出：

### 1. 矛盾结构拆解
- 本章用了哪种矛盾类型？
- 矛盾如何推进剧情？
- 当前处于"压迫→解决→新矛盾"循环的哪个阶段？

### 2. 期待感工程
- 本章制造了哪些期待？（短钩/中钩/长钩）
- 兑现了哪些之前的期待？
- 信息差类型是什么？（读者知道角色不知道 / 反之）
- 期待感密度：每多少字一个新期待点？

### 3. 人设技法
- 新角色用了什么类型模型？
- 贴了什么标签？
- 是顺承还是打破？
- 角色关系网如何编织？

### 4. 情绪节奏
- 压迫层数和释放方式
- 最长平淡段有多少字？
- 情绪波动频率

### 5. 可复刻技法（最重要）
- 这个章节中，哪些手法可以直接拿来用？
- 具体怎么用？给出模板/公式

## 六、三方阵营论（剧情延伸与逻辑完善）

### 核心观点
- 任何网文阵营分三方：**主角方、敌方、第三方（中立方）**
- 纯粹主角vs敌人的二元对立容易腻、容易刻意、配角没戏份
- 第三方的关键作用：**完善逻辑**（不是只用来围观震惊的）

### 主角方与敌方的两种延伸方向

| 方式 | 做法 | 效果 |
|------|------|------|
| ① 友军引出矛盾 | 主角的朋友/后宫被敌人盯上→主角挺身而出 | 矛盾主体从友军转到主角，更自然 |
| ② 敌人套娃 | 打了小的a→牵出敌方bcd势力 | 矛盾从小喽喽升级到大势力，层次丰富 |

### 第三方的【完善逻辑】功能

**为什么需要完善逻辑：**
- 反派不降智（有合理动机才针对主角）
- 主角不降智（有合理理由才出手帮忙）
- 友军不降智（不无理由倒贴/帮忙）
- 逻辑闭环 → 情节真实感 → 读者不弃书

**网文也需要真实感：**
- 不是设定要真实，是逻辑要合理
- 人物不降智，装逼要有脑
- 设定再天马行空，逻辑也要自圆其说

### 阵营关系的两种来源

**第一种：设定自带（一般存于开头）**
- 家人 = 天生友军（动机：亲情）
- 纨绔公子 = 天生敌方（动机：看上妹妹美色）
- 需要铺叙各方动机，不能空设定

**第二种：第三方转换（需要完善转换动机）**
- 第三方→友军：需要合理理由（许诺奖励/共同利益/情感认同）
- 第三方→敌方：需要合理理由（利益冲突/被牵连/误会）

### 动机完善的核心方法：情绪助燃

**公式：情绪 = 动机的助燃器**
- 情绪越足 → 读者与角色越能感同身受 → 动机越被认可

**铺垫动机的层数示例（复仇动机）：**
1. 原身被毒死，推断是纨绔下手（第一层：复仇）
2. 受原主记忆影响，与家人感情深（第二层：亲情）
3. 醒来后家人担忧之色未褪（第三层：情感细节）
4. 晚餐好吃好喝补身子（第四层：行为体现）
5. 家境贫寒，父母日夜劳作培养主角（第五层：牺牲感）
6. 药物很贵，家人欠债凑药费（第六层：亏欠感）
7. 妹妹想从了纨绔换取家庭安稳（第七层：绝境感）

**注意：情绪别一直压！**
- 压太低读者看累了会弃
- 波浪式：压一会→介绍金手指/复仇计划→回升情绪→拉期待
- 爽文情绪一定是波浪式的

### 主角方内部矛盾（特例）

**为什么主角方也要有矛盾：**
1. 调剂剧情单一（纯打怪升级容易腻）
2. 来自在乎的人的背刺比敌人更疼，更能调动情绪

**三种浅背刺方法（能拉回来的）：**

| 方式 | 做法 | 关键 |
|------|------|------|
| 误会 | 甩锅给原主/系统，主角是被误会的 | 误会解除过程 = 剧情线 + 爽点 |
| 理念分歧 | 配角与主角理念不同→配角被打脸→认同主角 | 主角理念永远是对的 |
| 证明实力 | 主角一步步攀升证明自己 | 赘婿文/升级文常用 |

### 阵营剧情构造总结公式

```
① 主角——敌方（最常见）
② 友军——敌方 →（合适动机）→ 主角——敌方
③ 主角——敌方a →（合适动机）→ 主角——敌方bcd（套娃）
④ 主角——友军（误会/理念分歧/证明实力）
```
可以②③组合使用。

### 强主角方 vs 弱主角方

| 类型 | 定义 | 能否装逼 | 适用题材 |
|------|------|----------|----------|
| 弱主角方 | 独立配角，脱离主角存在 | ❌ 他们装逼跟主角无关 | 传统升级文 |
| 强主角方 | 与主角一体的群体（领民/弟子/学生） | ✅ 他们装逼=主角装逼 | 领主文/门派文/家族文 |

**强主角方的装逼扩展：**
- 传统升级文：只有主角一个人装逼，范围小
- 领主文：所有领民都能装逼 → 爽点翻倍
- 门派文：弟子人前显圣 → 等于主角的宗门在装逼
- 主角甚至不用出场，通过强主角方间接装逼

**经典案例：**
- 末世领主文：外人被领民救下→领地各种珍贵资源随便给→外人震惊→领民骄傲说"这都是领主大人的功劳"
- 门派建设文：废柴弟子被教导后挖掘天赋→吊打各大圣地天才→读者爽（因为是主角宗门的弟子）
