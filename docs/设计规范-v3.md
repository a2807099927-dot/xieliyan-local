# 写梨眼 v3.1 UI 设计方案（浅色极简 · 全功能保留）

> 状态：草案 v0.2 · 2026-07-27
> 变更说明：v3.0（暖纸朱砂方向）被参考图推翻。用户指明目标感觉为**浅色、留白、克制的极简风**（参考 OpenCode 类 AI 编辑器截图），且**写梨眼现有全部功能入口不得消失**。本版按此重做。
> 配套 mockup：(1) 浅色极简主视图（保留全部功能）

## 〇、目标风格的视觉语言（参考图分析）

| 元素 | 参考图做法 | 迁移到写梨眼 |
|------|-----------|--------------|
| 底色 | 纯白 / 极浅灰分区（#FFFFFF / #FAFAF9） | 全界面浅色主导 |
| 分隔 | 几乎无边框，用留白和 1px 极浅灰线 | 删除所有重边框、阴影 |
| 点缀色 | 单一克制绿（状态点 / AI 建议高亮） | 绿 = AI 语义；近黑 = 主按钮 |
| 正文 | 衬线 + 大行距 + 窄行宽 | 保留，思源宋体 |
| UI 文字 | 小号无衬线，大量 10~12px | 保留层级但提高可读下限 |
| 章节列表 | 卷折叠 + 字数字样 + 状态点 | 直接借鉴 |
| AI 面板 | 对话式 + token 条 + 模型选择器 | 写梨眼右栏改为对话式为主 |
| AI 建议 | 绿色高亮块内联在对话/正文 | 沿用，语义化增强 |

**与 v3.0 的核心差异**：朱砂暖色 → 中性浅灰 + 克制绿；卡片式功能入口 → 对话式 + 标签页；暗主题主导 → 浅色主导（暗色保留为可选）。

- 多章 Tab（参考图样式，替代/并存现有多书 Tab）

### 1.5 顶部 TitleBar（极简三段）

左：书名 · 章名；中：模式切换（写作 / 工坊）；右：保存态 · 云同步态 · 更新小红点 · 窗口控制。

## 二、设计令牌（v3.1 定稿）

### 2.1 色彩

| token | 浅色值 | 深色值（可选主题） | 用途 |
|-------|--------|---------------------|------|
| `--bg` | #FFFFFF | #1B1B1A | 编辑器主区 |
| `--panel` | #FAFAF9 | #222220 | 左右面板 |
| `--rail` | #F7F7F5 | #1E1E1D | 图标栏 |
| `--line` | #ECECEA | #333331 | 唯一允许的 1px 分隔 |
| `--ink` | #20201F | #E8E8E4 | 主文本 |
| `--ink-2` | #8B8B87 | #9B9B95 | 次要文本 |
| `--ink-3` | #B5B5B0 | #6B6B66 | 提示文本 |
| `--accent` | #2F2F2D | #E8E8E4 | 主按钮（近黑，克制） |
| `--ai` | #4C9A6E | #6FBF8F | **AI 语义绿**：状态点、建议、token 条 |
| `--ai-bg` | #E8F5EC | #1F3A2A | AI 建议高亮底 |
| `--ai-ink` | #2F6B45 | #8FD4A8 | AI 建议文字 |
| `--danger` | #C25E4C | #D8765F | 删除（仅确认场景） |
| `--warn` | #C9971C | #DBAF45 | 警告 |

规则：
- **绿 = AI 做的事**（建议、生成、状态点、token），人做的事用中性色
- 主按钮用近黑而非彩色 —— 克制的关键
- 除 `--ai` 外禁止引入其他彩色到常规界面

### 2.2 排版

- 正文：思源宋体（Noto Serif SC）15~16px / 行高 1.9 / 段距 1em
- UI：系统无衬线（思源黑体/苹方回退）11~13px
- 章名：20~22px / 600（UI 体系内允许此一处 600+）或衬线 500
- 字重：常规 400、强调 500；仅章名可 700
- 章节列表 10~11px 字号须保证行高 ≥ 20px（可读下限）

### 2.3 间距 / 圆角 / 阴影

- 间距：4 8 12 16 24 32（面板内边距 12~16，阅读区 ≥ 32）
- 圆角：5（小件）/ 6（卡片）/ 10~11（胶囊）
- **零阴影**。弹层用 1px `--line` + `--panel` 底色即可

### 2.4 动效

- 全部 ≤ 200ms，ease-out
- AI 生成文字流式淡入；尊重 prefers-reduced-motion

## 三、组件规范

### 3.1 按钮

- primary：近黑实心 + 白字（仅一个/屏）
- secondary：白底 + 1px `--line` + ink 字
- AI 动作按钮：`--ai-bg` 底 + `--ai-ink` 字（表示"这是 AI 的活"）
- 标签动词开头：续写、应用、跳过、再生成、插入正文

### 3.2 状态点（借鉴参考图）

章节列表右侧 2~3px 圆点：
- 绿实点：已保存且已同步
- 绿圈：本地已存未同步
- 灰点：未保存/空章

### 3.3 AI 建议块

- 对话内：`--ai-bg` 圆角块 + 行号
- 正文内联：整块 `--ai-bg` + 左下小注"✓ AI 续写已插入 · 撤销 Ctrl+Z"
- 删除建议：`--danger` 删除线 + 浅红底（不用绿，避免混淆）

### 3.4 对话卡片（右栏）

- 白底 + 1px `--line` + 6px 圆角
- 标题行：9~10px 500 加粗（梳理剧情走向 / 写入章节 · xxx）
- 工具过程卡可折叠，默认收起

### 3.5 模型选择器 / token 条

- token 条：细胶囊，绿色进度 + 灰底，文字 8~9px
- 模型选择器：胶囊样式 + ⚡ + 模型名，点击展开列表

## 四、关键界面细则

### 4.1 主视图（见 mockup）

四段横向：36px 图标栏 / 158px 章节面板 / 自适应编辑区 / 194~320px AI 面板（可拖拽、可折叠）。

编辑区：
- 章名左上（或居中）20px 粗，与正文同源衬线
- AI 插入块紧随正文流，带撤销提示
- 场景分隔用 `···` 居中，9px 浅灰

### 4.2 暗色主题（可选保留）

- 全套 token 有深色值（见 2.1 表），一键切换
- 现有用户暗紫主题 → 自动迁移到 `--bg #1B1B1A` 中性暗（不再发紫），保留 6 个月"经典暗紫"开关

### 4.3 AI 改稿视图（沿用 v3.0 §4.5 结论，仅换色板）

- 摘要条 + 逐条卡片 + 底部动作条不变
- 新增=`--ai-bg`/`--ai-ink`；删除=浅红底+删除线；调序=`--warn` 浅底
- 按钮措辞沿用：跳过 / 应用 / 再试 / 应用所有 N 处修改

## 五、落地计划（修订版）

### 阶段 1 — tokens + 全局换肤（1 周）
1. `src/styles/tokens.css`：上表全部变量（浅/深双套）
2. `tailwind.config.js` 映射语义色（bg/panel/rail/line/ink/ai…）
3. `styles.css`（79KB）硬编码色 → 变量；先保布局不动
4. 主题切换器挂到设置

### 阶段 2 — 四段骨架 + 图标栏（1~2 周）
1. `GlobalSidebar` 改 36px 极简图标栏（9+1 入口）
2. 章节面板标签化（章节/笔记/档案）
3. 编辑区多章 Tab（复用现有 Tab 体系）
4. TitleBar 三段极简

### 阶段 3 — 右栏对话化（2 周，工作量最大）
1. 新 `AssistPanel`：续写（对话式）为默认页
2. Agent / 大纲 / 角色 / ⋯ 标签迁入
3. token 条 + 模型选择器 + 快捷指令条
4. AI 建议块组件（对话内 + 正文内联两型）

### 阶段 4 — Diff/改稿 + 一致性收尾（1 周）
1. 改稿视图换新色板
2. 全书查找替换、导出、设置等次要界面过一遍
3. axe-core 对比度 CI；截屏回归测试

### 风险

| 风险 | 缓解 |
|------|------|
| 浅色切换后老用户不适应 | 深色全套 token 同步交付 + 经典暗紫保留 6 个月 |
| 79KB styles.css 硬编码替换易漏 | 先做变量双写（旧值兜底），grep 清单逐文件核销 |
| 右栏对话化改动大 | 续写页先行，Agent 页原样迁入第二阶段 |
| 小字号可读性 | 章节列表 ≥10px、行高 ≥20px 作为硬约束 |
