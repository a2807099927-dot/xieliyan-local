# 写梨眼：写作思考边界收敛 —— 章纲层思考，正文层纯执行

> 版本：v1（2026-08-03）
> 决策（用户拍板）：
> **思考/搜索/审查只发生在「产出章纲」的环节；正文一律纯执行——自定义提示词 + 章纲 → 直接生成正文，不做任何写前复盘/审查。**
> 单章（Agent/编辑器续写）同样如此：自定义提示词 + 章纲 → 正文，无繁复操作。

---

## 0. 最终架构原则

```
【章纲层】（思考 + 搜索 + 审查都在这）
  ① 剧情规划（arcPlan）
  ② 同题材研究（web_search + 读章节）
  ③ 大纲审查（剧情有效性检查）
        ↓ 产出：完整章纲（含场景节拍/章末钩子/阶段目标）
【正文层】（纯执行，无思考）
  用户自定义提示词（风格单入口） + 章纲 + 前文 context
        ↓ 直接扩写正文
```

| 路径 | 章纲层 | 正文层 |
|---|---|---|
| 工坊批量 | 规划 + 搜索 + 审查（全部） | 自定义提示词 + 章纲，纯执行 |
| 单章（Agent/编辑器） | 章纲由用户确认/已有 | 自定义提示词 + 章纲，纯执行 |

## 1. 现状差距（已核实）

| 项 | 现状 | 与原则差距 |
|---|---|---|
| Agent 单章正文前 | `runPreWriteReflection` 五问复盘（useAgentSession.ts:456/749 + creativeTools.ts 工具内部） | ❌ 违反「正文纯执行」 |
| 工坊章纲层·搜索 | 无（只有 arcPlan 规划） | ❌ 缺同题材研究 |
| 工坊章纲层·审查 | 无（细纲生成后直接进正文） | ❌ 缺大纲审查 |
| 单章正文输入 | 复盘决策 + 章纲 + 设定卡… | ❌ 应简化为「自定义提示词 + 章纲」 |

## 2. 任务清单

### T1 单章正文去掉写前复盘（默认关，保留开关）

- **现状**：`preWriteReflection` 默认 true，单章（runAgent/rewriteSelection/write_chapter_body）正文前跑五问复盘
- **改法**：默认 **false**（`preWriteReflection !== true`），单章正文不再跑复盘；设置页开关保留，用户想开还能开
  - `src/types/ai.ts` 注释更新默认值语义
  - `AgentSettingsTab.tsx:78` 默认勾选逻辑改（`!== true`）
  - 相关测试同步
- **文件**：`src/types/ai.ts`、`AgentSettingsTab.tsx`、`preWriteReflection.test.ts`
- **验收**：新配置单章正文直接写（无复盘调用）；开关打开时行为不变

### T2 工坊章纲层补同题材研究

- **位置**：arcPlan 规划之后、细纲生成之前（orchestrator.ts 循环前）
- **实现**：复用 `buildResearchPrompt` + `web_search`（已有能力），一次调用产出研究结论
  - 搜索 query：`题材 + 金手指 + 经典 完本`
  - 结论注入：传进 `generateOutlineChunk` 的 user prompt（带来源标注）
- **文件**：`src/workshop/arcPlanPrompt.ts`（或新 research 模块）、`orchestrator.ts`
- **验收**：工坊批量前先搜索同题材，研究结论进细纲生成 prompt；搜索失败降级不阻塞

### T3 工坊章纲层补大纲审查

- **位置**：全部细纲生成完后、正文批量开始前
- **实现**：复用 wizard 的 `buildOutlineReviewPrompt`/`parseOutlineReview`，对已生成细纲做剧情有效性检查
  - 有 `invalid`/`needs_rework` 章 → 标记并重跑该章细纲（带审查意见）
  - 用户可跳过修改直接进正文
- **文件**：`src/workshop/orchestrator.ts`、复用 `src/Agent/plotPlanning.ts`
- **验收**：细纲生成后先审查，无效章能触发重写；审查失败降级不阻塞

### T4 测试 + 全量验证

- 更新：preWriteReflection 默认值相关测试
- 新增：工坊研究注入、审查重写流程测试
- `npx tsc --noEmit` + `npx vitest run` 全绿
- **验收**：全量测试绿，无回归

## 3. 边界（不做）

- **不彻底删除写前复盘代码**——保留开关，用户可开（防反复）
- **不改单章章纲获取方式**（用户确认章纲/已有细纲，正文直接吃）
- **不动正文生成逻辑本身**（BODY_SYSTEM_CORE / buildWriterSystemPrompt 不变）
- **不做「正文自动审查」**——审查只在章纲层，正文不审查（用户明确）

---

## 4. 验收标准

1. 新配置下单章「写第一章」→ 自定义提示词 + 章纲 → 直接正文，**无复盘调用、无审查**
2. 工坊批量：先规划 → 再搜索 → 再细纲 → 审查 → 正文
3. 开关打开时单章写前复盘行为不变（保留能力）
4. tsc 0 错误 + 全量测试绿
