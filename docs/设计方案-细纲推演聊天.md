# 细纲推演聊天面板（VIP 功能）

> 设计时间：2026-05-26  
> 状态：待开发  
> 入口：大纲看板页面底部抽屉

---

## 核心逻辑

用户在大纲看板中，通过底部抽屉式聊天面板与 AI 对话，推演下一章的细纲。

## 交互方式

1. 大纲看板底部有一个可收放的 tab 按钮（如"🧠 细纲推演"）
2. 点击后从底部向上弹出聊天面板（占窗口下半部分，约 40-50% 高度）
3. 再次点击或拖拽可收起
4. 聊天面板内：左侧是对话区，右侧可选显示当前章节信息

## AI 上下文

每次对话自动注入：
- 前 10 章的智能整理摘要（plotSynopsis）
- 当前选中章节的细纲（如果有）
- 写作风格指令
- 系统指令："你是网文剧情规划师，帮助作者推演下一章的细纲"

## 用户操作

- 正常聊天：讨论情节走向、冲突设计、角色安排
- "应用到细纲"按钮：把 AI 最后一条回复（或用户选中的内容）填入指定章节的细纲字段
- 可以切换目标章节（默认是最新的未写章节）

```

│  ├─────────────────────────────────────────────┤   │

```

## VIP 门控

- 免费用户：点击"细纲推演"按钮后提示 VIP 专属
- VIP 用户：完整使用聊天推演功能

## 技术实现要点

1. 在 OutlineBoard 底部添加可收放的抽屉面板
2. 聊天逻辑复用 `electronAPI.ai.chat` 流式调用
3. 消息历史存在组件 state 中（不持久化，关闭窗口清空）
4. "应用到细纲"调用 `handleUpdateChapterField(chapterId, 'notes', text)`
5. 上下文构建复用 `buildMemoryContext` 逻辑
