# 批量章节生成（VIP 功能）

> 设计时间：2026-05-26  
> 状态：待开发  
> 入口：大纲看板页面

---

## 核心逻辑

用户在大纲看板为每章填好细纲后，点击"批量生成"按钮，系统逐章自动执行：

```
循环（从起始章到结束章）：
  1. 组装 prompt = 写作风格指令 + 前10章智能整理 + 当前章细纲
  2. 调 AI 生成正文 → 流式写入章节 content
  3. 生成完毕 → 自动对该章正文执行智能整理
  4. 整理结果存入该章档案
  5. 进入下一章
```

## Prompt 组装规则

```
[系统指令]
你是一位网络小说作家，请根据以下信息写出本章正文。

[写作风格]
{用户配置的 styleInstruction 或内置预设}

[前文剧情档案（最近10章的智能整理）]
第N章：{摘要 + 关键节点 + 角色状态变化}
第N+1章：...
...

[本章细纲]
{用户填写的当前章节细纲内容}

[输出要求]
请根据细纲完整写出本章正文，自然结束即可。
```

## 前10章智能整理取法

- 第 1 章：无前文档案
- 第 2-10 章：取前面所有已整理章节
- 第 11+ 章：取前 10 章的整理结果

## 用户交互

### 入口
- 大纲看板页面，添加"批量生成"按钮

### 生成前
- 用户选择起始章节（默认从第一个有细纲但无正文的章节开始）
- 确认后开始

### 生成中
- 灵动岛显示进度："正在生成第 3/10 章..."
- 支持随时暂停（当前章生成完毕后暂停，不会中断半截）
- 暂停后可继续，从下一章接着跑

### 生成后
- 每章正文自动写入对应章节
- 每章智能整理自动存入档案
- 用户可以事后逐章修改

## 暂停与续跑

- 持久化一个 `batchGenerateState`：
  - `bookId`
  - `startChapterIndex`
  - `currentChapterIndex`
  - `status`: 'running' | 'paused' | 'completed'
- 暂停：等当前章生成+整理完毕后停止循环
- 继续：从 `currentChapterIndex + 1` 恢复

## 错误处理

- AI 生成失败：自动重试 1 次，仍失败则暂停并通知用户
- 智能整理失败：跳过整理继续下一章（整理不是必须的，不阻塞流程）
- 网络断开：暂停，恢复网络后可继续

## VIP 门控

- 免费用户：大纲看板正常使用，但"批量生成"按钮点击后提示 VIP 专属
- VIP 用户：完整使用批量生成流水线

## 技术实现要点

1. **前端**：在 OutlineBoard 组件中添加"批量生成"按钮 + 进度状态管理
2. **生成逻辑**：复用现有 `useAiChat` 的流式调用，但改为自动化循环
3. **智能整理**：复用 `MemoryBankModal` 中的 `analyzeOneChapter` 逻辑
4. **状态持久化**：存在 book.json 或独立文件中，支持中断续跑
5. **灵动岛**：复用 `useIslandStore` 显示进度 + 暂停按钮

## 依赖的现有模块

- `src/hooks/useAiChat.ts` — AI 调用
- `src/components/modals/MemoryBankModal.tsx` — 智能整理逻辑
- `src/store/useIslandStore.ts` — 灵动岛进度
- `src/store/useBookStore.ts` — 章节读写
- `src/store/useConfigStore.ts` — 写作风格配置
